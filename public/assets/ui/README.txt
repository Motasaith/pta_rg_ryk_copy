Loading-screen key art goes here.

Save the image as ONE of these and it becomes the loading screen background
automatically (no code change; in dev just refresh):

    loading.webp     <- checked first
    loading.jpg
    loading.png

Recommended: about 2048-2752px wide, under 1 MB.

If none is here, the loader falls back to the built-in procedural artwork and the
browser console logs a 404 for each name it tried. That is expected and harmless
until the art is installed.
